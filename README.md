# Ossa

Ossa is a local-first protocol designed to protect users' security and privacy.
This repository contains Ossa's core libraries, which are implemented in Rust.

## Contributing

Contributions are welcome!
Consider opening an issue to seek alignment before submitting a pull request.
AI use is welcome, however you are responsible for the contents of your contributions.
Please be sure to review and understand all contributions, and keep pull request sizes minimal for reviewing.

Before we can accept contributions from you, you must agree to the [Contributor License Agreement](/CLA.md).
A bot will comment on your first pull request with instructions.
Sign by replying with the requested text.
